# Process artifacts

These are the original planning and queue records, retained as historical evidence. They describe the earlier `naano-web/` layout and refer to screenshots on the original machine. They are not a claim that every queued step was completed, or a current instruction to continue the clone.

The current application lives at the repository root. The old unattended Cursor continuation hook is no longer registered. `QUEUE-STATUS.json` is an unchanged historical snapshot, not a completion report.

Capture verification and provenance are documented in [CAPTURE-TEST.md](../../CAPTURE-TEST.md). Current scope and validation commands are in the [repository README](../../README.md).
