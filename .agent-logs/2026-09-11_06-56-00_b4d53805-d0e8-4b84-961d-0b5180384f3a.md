The site is a **Next.js** app in `naano-repo\naano-web`, not in `naano-repo`. That’s why `npm run dev` and `npm install` failed — there is no `package.json` in the parent folder.

You already have Node/npm working. From PowerShell:

```powershell
cd "C:\Users\PC\OneDrive - ACME ONE\Desktop\Naano\naano-repo\naano-web"
npm install
npm run dev
```

Then open **[http://localhost:3000](http://localhost:3000)** in your browser.

That’s the home page. Other useful URLs once the server is running:

| Page | URL |
| --- | --- |
| Home | http://localhost:3000 |
| Creators | http://localhost:3000/creators |
| Agencies | http://localhost:3000/agencies |
| Login | http://localhost:3000/login |
| Dashboard | http://localhost:3000/dashboard |

Leave that terminal open while you browse. Stop the server with `Ctrl+C`.

**If `npm install` complains about Node:** Next.js 16 needs a current Node (18+; 20 or 22 is safest). Check with `node -v`.

No `.env` file is required for a local preview — this is a frontend clone with local/seeded data, not a separate backend.
