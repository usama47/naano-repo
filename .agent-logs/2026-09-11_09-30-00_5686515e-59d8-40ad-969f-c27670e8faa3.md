There is **no real backend**. Naano is a Next.js App Router clone that fakes a server with TypeScript seed files and three thin API routes.

## Architecture

Everything lives in `naano-web`. There is no Laravel API, database, Prisma, Supabase, or auth library. `package.json` is frontend-only (Next, React, TanStack Query, Recharts).

Data is compiled into the app as modules:

| Module | Role |
| --- | --- |
| `lib/data/creators.ts` | Seeded marketplace creators |
| `lib/data/campaigns.ts` | Seeded brand campaigns + collabs |
| `lib/data/creator-app.ts` | Demo signed-in creator, wallet, earnings, messages |
| `lib/data/filter.ts` | In-memory filter/sort |
| `lib/content/*` | Static blog/tools copy |

Dashboard pages import those modules directly. Login does not check credentials: the form’s `action` is `/dashboard`, so submit just navigates there. The “session” is a constant (`sessionCreator` = first seed creator).

## The three API routes

These are Next.js Route Handlers, not a separate service:

- **`GET /api/creators`** — reads the seed array, applies query-string filters, returns JSON. The marketplace explorer calls this via TanStack Query.
- **`GET /api/campaigns`** — returns the seeded campaign list.
- **`POST /api/campaigns`** — validates a brief, then **echoes** a fake draft (`cmp_xxxxx`) plus UTM links. Nothing is stored. The route comment says so: *“The demo has no persistence layer.”*
- **`POST /api/selection`** — accepts JSON and returns `{ ok: true, received: body }`.

So the “backend” is an in-memory demo: reads are seeds, writes are echoed and discarded on refresh.

It is interactive in the browser. It is not a live product with a server that remembers anything.

You can filter creators, shortlist them, fill the selection and campaign-brief forms, “sign in,” and walk the dashboard. Those screens use client components, TanStack Query, and the `/api/*` routes.

What you cannot do is persist work. Filters and form results live in that session. Campaign POST echoes a fake draft and drops it. Login is a visual stub that just sends you to `/dashboard`. Refresh and the seeded data is back.

So: a clickable Next.js clone of Naano, not a static brochure, and not a real backend either.
