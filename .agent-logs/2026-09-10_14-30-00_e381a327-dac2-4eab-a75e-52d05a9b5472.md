Your current folder (`Naano`) is empty, so you can clone straight into it or into a new folder.

## In Cursor

1. Open the Command Palette (`Ctrl+Shift+P`).
2. Run **Git: Clone**.
3. Paste the repo URL (HTTPS or SSH).
4. Pick a folder (or use this workspace).
5. When prompted, open the cloned folder.

You can also use **File → Clone Git Repository**.

## From the terminal

```powershell
git clone https://github.com/OWNER/REPO.git
```

To clone into the current empty folder:

```powershell
git clone https://github.com/OWNER/REPO.git .
```

SSH instead of HTTPS:

```powershell
git clone git@github.com:OWNER/REPO.git
```

## GitHub CLI (if you use `gh`)

```powershell
gh repo clone OWNER/REPO
```
